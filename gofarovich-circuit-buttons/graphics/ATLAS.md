# Атласы спрайтов

Сборщик: `../tools/build_atlas.py` (Python + Pillow). Тайл Factorio = 64 px (HR),
но арт **центрирован в ячейке 128×128** (паддинг 32 px со всех сторон) — место
под текстуры, вылезающие за футпринт сущности. В игре ячейка рисуется со `scale =
0.5`: центральный арт остаётся ровно 1 тайл, паддинг уходит внахлёст. Атлас 4×2 =
**512×256**.

## Раскладка (4 столбца × 2 строки, ячейка 128, координаты левого-верхнего угла)

```
(0,0)   toggle-on   (128,0)   terminal   (256,0)   toggle-off   (384,0)   terminal
(0,128) tick-down   (128,128) terminal   (256,128) tick-up      (384,128) terminal
```

- ряд 0: тогл вкл, кнопка выкл (повёрнута=терминал), тогл выкл, кнопка вкл (повёрнута=терминал)
- ряд 1: кнопка вкл (`tick-down`), тогл выкл (повёрнут=терминал), кнопка выкл (`tick-up`), тогл вкл (повёрнут=терминал)

«Повёрнутые» ячейки = сторона-терминал (`terminal.png`).

## Файлы

| Файл | Размер | Статус |
|---|---|---|
| `atlas.png` | 512×256 | основной арт (8 кадров), подключён в `data.lua` |
| `atlas-shadow.png` | 512×256 | тень, выводится из `atlas.png` через `tools/build_shadow.py`; подключена слоем `draw_as_shadow` |
| `husk.png` | 256×128 | остов/remnant: 2 вариации (рандом), подключён через `corpse`. **Заглушка — заменить артом** |
| `icon-pulse.png` / `icon-switch.png` | 128×128 | иконки, выводятся из `atlas.png` через `tools/build_icons.py` |

(снег/frozen нет — constant-combinator не замерзает.)

Пересборка:
- `python tools/build_atlas.py` — атлас из плиток `tools/src/` (перетирает ручной `atlas.png` — осторожно);
- `python tools/build_shadow.py` — тень из текущего `atlas.png`;
- `python tools/build_husk.py` — остов из текущего `atlas.png`;
- `python tools/build_icons.py` — иконки из текущего `atlas.png`.

> Внимание: `build_atlas.py` пересобирает `atlas.png` из `tools/src/` и затрёт ручные правки. Если `atlas.png` рисуется вручную — правь его напрямую, а тень/остов гени из него (`build_shadow.py`/`build_husk.py`).
