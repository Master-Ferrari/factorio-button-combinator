# button-combinator

Мод для Factorio 2.0. Автор: **gofarovich**.

Добавляет два предмета 1×1 для логической сети:

- **Timer button combinator** (`gofarovich-bc-pulse`) — по клику выдаёт сигнал на N тиков (длительность настраивается).
  Внутреннее имя прототипа осталось `...-pulse`, чтобы не ломать сейвы и блюпринты.
- **Switch button combinator** (`gofarovich-bc-switch`) — двухпозиционный переключатель.

Рецепты открываются технологией **Circuit network** (2 медных провода + 1 электронная плата).

## Как это работает (трюк с поворотом)

В Factorio клик по объекту делает ровно одно — открывает его GUI. Обойти это нельзя,
поэтому используется идея с двумя «лицами»:

- Обе кнопки — это перекрашенный **constant combinator**. У него есть GUI, поэтому клик
  по нему гарантированно вызывает событие `on_gui_opened`.
- В `on_gui_opened` мод **мгновенно закрывает** ванильный интерфейс комбинатора
  (`player.opened = nil`) и дальше смотрит на сторону объекта (перёд/зад):
  - **перёд** (лицо-кнопка) → клик трактуется как нажатие;
  - **зад** (лицо-терминал) → открывается собственное окно настроек.
- **4 направления сущности кодируют состояние** `(сторона, вкл/выкл)`, поэтому нужный
  кадр рисуется как обычный спрайт сущности — с Y-сортировкой по глубине, одним слоем,
  без оверлеев и `rendering` (это и есть фикс артефактов наложения и «спрайт поверх
  игрока»):
  - `north` = перёд-выкл, `east` = перёд-вкл, `south` = зад-выкл, `west` = зад-вкл.
  - «перёд» = north/east, «зад» = south/west (так `is_button_face` остаётся верным).
- Поворот (R) перехватывается в `on_player_rotated_entity`: меняет **сторону**
  (перёд ↔ зад), сохраняя текущее вкл/выкл. Нажатие меняет вкл/выкл, сохраняя сторону.
- Чтобы провода не «прыгали» при смене направления, все 4 точки подключения
  уравнены в `data.lua` (`circuit_wire_connection_points`).

Сигнал выдаётся через логическую секцию самого комбинатора (`set_output` в
`control.lua`), то есть кнопка — полноценный источник сигналов без скрытых сущностей.

## Интерфейс настроек (лицо-терминал)

Одинаковый у обеих кнопок:

- **Сигнал активного состояния** — что выдавать при нажатии/включении.
- **Сигнал неактивного состояния** — что выдавать в покое (можно оставить пустым).

У импульсной кнопки дополнительно чекбокс **«Обрывать по фронту (1 тик)»** (включён по умолчанию):

- **Включён** — клик выдаёт активный сигнал ровно **один тик**, текстура «нажато»
  видна один кадр, играет один звук.
- **Выключен** — режим «зажатия». **Важное ограничение API**: в Factorio у модов нет
  события «кнопка мыши отпущена», отследить реальную длительность зажатия невозможно.
  Поэтому реализовано ближайшее к ТЗ поведение: первый клик «зажимает» кнопку
  (активный сигнал + звук нажатия), следующий клик «отпускает» (звук отпускания).
  Это же автоматически решает проблему залипания — второй клик не блокируется и
  всегда снимает нажатие. Если при «зажатой» кнопке поставить чекбокс обратно,
  кнопка тоже отпускается.

Значения сигналов всегда равны **1**. Состояние кнопки переживает сохранение/загрузку.
Копирование настроек через Shift+ПКМ → Shift+ЛКМ (copy-paste settings) поддерживается
(сигналы, режим, описание). **Чертежи (blueprint) тоже поддерживаются**: сигналы,
режим `edge`, состояние вкл/выкл и описание сохраняются через теги чертежа
(`on_player_setup_blueprint` → теги → `on_built`).

Нюанс: если импульсную кнопку в режиме «фронт» поймать чертежом ровно в момент
1-тикового импульса (практически невозможно вручную), она восстановится «нажатой»;
любой следующий клик это снимает.

## Звуки

Сейчас оба звука — ванильный `__core__/sound/gui-click.ogg`:

- `gofarovich-bc-press` — нажатие (volume 0.7);
- `gofarovich-bc-release` — отпускание (volume 0.6, speed 0.8 — чуть ниже тоном).

Звук играет на поверхности в точке кнопки (слышат все рядом). Заменить — в конце
`data.lua` (прототипы `type = "sound"`), можно подставить свои `.ogg` из папки мода.

## Текстуры (атлас)

Игре поставляется **атлас** `graphics/atlas.png` (512×256 = 4×2 ячейки по 128×128).
Тайл = 64 px, но арт центрирован в ячейке 128 с паддингом 32 px (запас под вылет за
футпринт); при `scale = 0.5` центральный арт = ровно 1 тайл. `data.lua` адресует
ячейки через `cell(x, y)`. Раскладка и сборка — в [graphics/ATLAS.md](graphics/ATLAS.md).

`data.lua` адресует ячейки через `cell(x, y)` и раскладывает их по 4 направлениям
сущности — `north/east/south/west` = `перёд-выкл / перёд-вкл / зад-выкл / зад-вкл`:

| Ячейка (x,y) | pulse | switch |
|---|---|---|
| перёд-выкл (`north`) | `(256,128)` | `(256,0)` |
| перёд-вкл (`east`)   | `(0,128)`   | `(0,0)` |
| зад-выкл (`south`)   | `(128,0)`   | `(128,128)` |
| зад-вкл (`west`)     | `(384,0)`   | `(384,128)` |

Иконки предметов — отдельные файлы `graphics/icon-pulse.png` / `icon-switch.png`
(в Factorio иконка не умеет брать под-регион атласа, только целый файл).

Нюансы:

- Все 8 кадров — это **обычные спрайты сущности** (по 4 направления на тип), движок
  сам выбирает нужный по направлению и сортирует по глубине. Никаких оверлеев/`rendering`.
- `tools/build_atlas.py` собирает атлас из плиток `tools/src/`, но «задние» кадры там
  пока заглушка (терминал) — финальные 8 кадров нарисованы вручную в `atlas.png`.
- `atlas-shadow.png` — тень (слой `draw_as_shadow`); `husk.png` — остов (`corpse`,
  процедурная заглушка). Снега/frozen нет — constant-combinator не замерзает.
- Отдельной текстуры для востока/запада нет — направления заклампены: восток = кнопка,
  запад = терминал.

## Точки подключения проводов

Унаследованы от ванильного constant combinator (`circuit_wire_connection_points`),
то есть красный/зелёный провода цепляются туда же, куда у обычного постоянного
комбинатора, для каждого из 4 направлений. Если под новые текстуры точки нужно
сдвинуть — переопредели `entity.circuit_wire_connection_points` в `make_button`
(`data.lua`): это массив из 4 элементов (N/E/S/W), у каждого `wire = {red = {x, y},
green = {x, y}}` и `shadow` с теми же полями, координаты в тайлах от центра.
LED-индикаторы активности комбинатора скрыты (`activity_led_sprites` пустой).

## Структура

```
button-combinator/
├── info.json          — метаданные мода
├── data.lua           — сущности, предметы, рецепты, звуки, спрайты-оверлеи
├── data-updates.lua   — добавление рецептов в технологию circuit-network
├── control.lua        — вся логика: клики, поворот, GUI, выдача сигналов
├── graphics/          — атласы (atlas*.png) + иконки + ATLAS.md
├── tools/             — build_atlas.py + src/ (исходные плитки, не шипятся)
└── locale/ru, en      — локализация
```

> `tools/` нужен только для пересборки атласов и в игре не используется —
> при желании можно исключить его из релизного zip.

## Установка для теста

Скопировать (или симлинкнуть) папку `button-combinator` в
`%APPDATA%\Factorio\mods\` и включить мод в игре.
